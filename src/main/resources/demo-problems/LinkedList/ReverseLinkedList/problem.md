# Reverse Linked List

Difficulty: Easy

Topics: Linked List, Recursion

## Problem

Given the `head` of a singly linked list, reverse the list and return its new head.

For this problem, JSON represents a linked list as an integer array in the `head` property.

## Examples

**Example 1**

Input: `head = [1,2,3,4,5]`

Output: `[5,4,3,2,1]`

## Constraints

- The number of nodes is in the range [0, 5000].
- -5000 <= Node.val <= 5000
