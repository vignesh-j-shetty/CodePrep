# Two Sum

Difficulty: Easy

Topics: Array, HashMap

## Problem

Given an integer array `nums` and an integer `target`, return the indices of the two numbers that add up to `target`.

You may assume exactly one solution exists. Return the answer in any order.

## Examples

**Example 1**

Input: `nums = [2,7,11,15], target = 9`

Output: `[0,1]`

## Constraints

- 2 <= nums.length <= 300000
- Exactly one valid answer exists.

Hidden performance tests use a 1500 ms execution limit. Aim for an O(n) solution.
